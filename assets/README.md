# 画像アセット

提供画像は次の名前でこのフォルダに置いてください。

- `hero.jpg` — ファーストビュー（フルブリード）
- `service-flow.jpg` — サービス流れ
- `service-care.jpg` — サービス補足
- `cta.jpg` — 登録 CTA 背景
- `map-florist-initial.svg` — フローリストマップ初期画面イメージ（実データなし）
- `map-lesson-initial.svg` — レッスンマップ初期画面イメージ（実データなし）

マップは実データを公開しない方針のため、LP／ガイドでは初期画面の静止画のみを使います。実マップはアプリログイン後のみです。
